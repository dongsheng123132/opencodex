# OpenCodex v0.4.0

## 发布方式

- 仅发布 `OpenCodex-v0.4.0-portable.zip`：解压后直接运行 `OpenCodex.exe`。
- ZIP 内置空白的 `portable-data/`，因此任务、快捷项和可选的临时 Claude Code 对话路由都会随该文件夹保存；不同文件夹中的绿色版互不串数据。
- 不发布曾在开发机启动过的 `portable-data`。其中可能包含个人项目路径、任务记录或本地 Key。
- 首次运行需要 Microsoft Edge WebView2。Windows 11 和多数 Windows 10 已自带；缺失时会在启动前说明原因，用户确认后从微软官方下载安装，失败或拒绝时会打开官方下载页。

## 新功能与改进

- AI 设置中心：展示本机检测到的 Claude Code、Codex、Hermes、Gemini CLI、OpenCode；默认尊重各 CLI 自己的配置，不读取或改写它们的配置文件。
- 可选为 OpenCodex 的结构化 Claude Code 对话设置临时兼容端点；不影响手动终端和其他 CLI。
- 终端恢复 xterm 原生默认调色板，不再提供或注入 OpenCodex 自定义配色。
- 中英双语界面、U-King 会话导入、会话排序/重命名/状态提示、终端快捷命令与复位、Codex 历史提示、Redline 复制及文件预览增强。

## 已知边界

- 同一绿色版文件夹不要同时开多个实例；不同文件夹可以各自独立运行。
- 旧版默认数据在 `~/.opencodex/`；若要保留历史，请在关闭 OpenCodex 后手动复制所需文件到新版本的 `portable-data/`。不要复制不需要携带的 `config.json`。
